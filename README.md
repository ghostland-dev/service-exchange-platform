# Service Exchange

Platform for exchanging services between users.

## Features

- Services and exchanges REST API
- Notifications
- Admin and analytics

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)

## Getting Started

```bash
git clone https://github.com/ghostland-dev/service-exchange-platform.git
cd service-exchange-platform
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: next lint

## Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fghostland-dev%2Fservice-exchange-platform)

Click the button to deploy your own copy on Vercel in one step.

Set these environment variables in the Vercel project settings (see `.env.example`):

- `NEXT_PUBLIC_DEV_SUPABASE_REDIRECT_URL`
